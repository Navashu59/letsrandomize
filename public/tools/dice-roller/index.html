Fairness and tabletop use

Each die result is generated independently in the browser using the site's shared randomization engine. Rolling multiple dice is equivalent to rolling each die separately and then adding the results and modifier.

This is useful for tabletop games, classroom probability examples, and quick random checks. For casino-style gambling or regulated play, use the official equipment and rules for that setting. See the methodology page for random source details.

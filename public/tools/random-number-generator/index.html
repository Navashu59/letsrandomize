Pseudo-Random vs True Random Numbers

Not all random number generators are created equal. Understanding the difference helps you choose the right tool for your needs.

FeaturePseudo-Random (PRNG)Cryptographic (CSPRNG)True Random (TRNG)
SourceAlgorithm + seedOS entropy poolPhysical phenomena
ExampleMath.random()Web Crypto API (this tool)Random.org (atmospheric noise)
Predictable?Yes, if seed knownNo (computationally infeasible)No (physically impossible)
SpeedVery fastFastSlow (needs hardware)
Good for games?YesYesOverkill
Good for security?NoYesYes

Our random number generator uses the Web Crypto API when available, which draws from your operating system's entropy pool. That is a strong choice for everyday number draws, classroom picks, games, and simple sampling, but it is not a certified or independently audited random draw system.

The science behind random numbers.

How this random number generator chooses values

The generator uses browser cryptographic randomness when available and maps that random value into the range you choose. When Unique Only is enabled, each generated number is removed from the available pool so it cannot appear twice in the same result.

This is appropriate for classroom picks, games, raffle-style number draws, practice data, and simple sampling. It is not a certified lottery system or audited compliance tool. For more detail on random sources and appropriate limits, see the methodology page.

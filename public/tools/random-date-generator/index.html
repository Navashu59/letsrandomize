How random dates are selected

The tool converts your start and end dates into a range, chooses a random offset inside that range, and formats the result for display. If you generate multiple dates with sorting enabled, the dates are selected first and then sorted for readability.

Use this for examples, practice data, writing prompts, schedules, and simple sampling. For legal deadlines, official lotteries, compliance assignments, or payroll decisions, use the required system of record instead. See the methodology page for randomization limits.

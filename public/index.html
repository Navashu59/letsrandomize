Why LetsRandomize?

LetsRandomize is a free collection of list randomizers, team generators, pickers, and number tools maintained by Sam Parker. Tools process your entries in the browser for the current session and use the browser Web Crypto API when available. No sign-up required. Just fast random results for everyday decisions, classes, games, and meetings.

For transparency, read how the tools handle user input and randomness in the randomization methodology, or contact the site through the contact page.

Chimp test scores

The chimp test is a visual memory game: numbers appear on a grid, disappear, and you click their positions in order. It is useful as a quick memory challenge, but it should not be read as an IQ score.

By Sam Parker | Updated Jun 7, 2026

Quick answer: A good chimp test score depends on the exact version, but remembering around 7-9 numbers is a solid online result. Higher scores usually reflect practice, visual strategy, a comfortable device, and sometimes a lucky layout.

What does the human benchmark chimp test actually measure?

It measures short visual working memory for positions and order. You need to notice where the numbers are, hold the locations briefly, and click them in sequence after the labels disappear. That is different from vocabulary, reasoning, problem solving, or general intelligence.

Is the chimp test an IQ test?

No. The popular "are you smarter than a chimp" framing is memorable, but the game is not an IQ test. A high score means you performed well on this narrow visual memory task. A low score does not mean you are unintelligent.

Why do chimp test scores improve with practice?

After a few attempts, you stop reading each number as a separate fact and start using visual patterns: clusters, paths, rows, corners, and relative positions. That practice effect is real, so compare your current score with your own previous scores rather than treating one attempt as a fixed ability.

How can I improve my chimp test score?

Try grouping nearby numbers, remembering a path through the grid, keeping your eyes near the center, and clicking slowly enough to avoid mistakes. Use the same device when comparing scores; a touchscreen, trackpad, and mouse can feel very different.

Why do people search for "are you smarter than a chimp"?

The online game is inspired by research on chimpanzee short-term memory tasks where young chimpanzees memorized number positions very quickly. The public web version is a simplified game-like challenge, not the same as a controlled lab experiment.

Frequently asked questions

What is a good chimp test score?

For many online versions, 7-9 is a solid result and 10+ is strong. Exact comparisons depend on the test version and how much you have practiced.

Does the chimp test measure intelligence?

No. It measures a narrow visual memory task, not general intelligence.

Can I improve my chimp test score?

Yes. Visual grouping, path memory, repetition, and device familiarity can all improve your score.
